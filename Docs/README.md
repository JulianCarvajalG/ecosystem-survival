# 📄 Project Documentation Overview

This repository contains several documents that represent different stages and formats of the **Ecosystem Survival** project. Each file serves a specific purpose, ranging from early design to formal presentation and communication of the project.

Below is a general description of each document included:

---

## 📘 Paper

The *paper* is the first formal academic version of the project. It follows a structured format similar to an IEEE-style article and focuses on presenting the core idea, motivation, and initial design of the game.

It includes:

* The problem context
* The conceptual idea of the game
* Initial design decisions
* A general explanation of algorithms and structures

👉 This document is more **theoretical and formal**, aimed at explaining *what the project is* and *why it matters*.

---

## 📗 Report

The *report* is a more detailed and evolving document that expands on the paper. It is oriented toward the **development process and final delivery**.

It includes:

* Consolidated design decisions
* Detailed explanation of algorithms (greedy and backtracking)
* Data structure design (linked list and tree)
* JSON communication structure
* Gameplay rules and system behavior
* Development roadmap and challenges

👉 This is the most **complete and technical document**, explaining *how the project works and how it will be built*.

---

## 🟪 Poster

The *poster* is a visual summary of the project, designed for quick presentation and communication.

It includes:

* Key concepts of the game
* Visual elements (board, symbols, mechanics)
* Simplified explanation of algorithms
* Main objectives and contributions

👉 It is meant to **communicate the project quickly and visually**, without going into deep technical detail.

---

## 📊 Slides

The *slides* are used for oral presentations of the project.

They include:

* A structured explanation of the problem and solution
* Visual aids for understanding the game
* Key technical components (algorithms, structures, flow)
* Highlights of progress and future work

👉 Their purpose is to **support a live explanation**, making the project easy to present and understand.
