# Ecosystem Survival Project

Welcome to the **Ecosystem Survival** project! This is an educational and interactive game designed to simulate ecosystem dynamics, where players manage animal species' survival using algorithmic decision-making. The game focuses on **greedy algorithms** for prioritizing the survival of the most vulnerable species, and **backtracking algorithms** for finding safe migration paths.
